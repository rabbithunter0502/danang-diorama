# Đà Nẵng · Diorama 3D

Faithful recreation of [danang-diorama.netlify.app](https://danang-diorama.netlify.app/) — a hand-drawn dusk/night 3D diorama of Da Nang built with Three.js.

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173/

## Controls

- **Overview / Painting view / Fireworks** — camera presets
- **Auto-orbit / Follow a car** — camera modes
- **Night / Dragon show / Clear sky / Sound** — scene toggles
- Drag to orbit, scroll to zoom
